# Soma updates

The update feed for Soma, a Mac app in beta testing. Soma checks
[appcast.xml](https://jamdoran.github.io/soma-updates/appcast.xml) once a day and offers new builds itself.

To install Soma for the first time, download **Soma.dmg** from the
[latest release](https://github.com/jamdoran/soma-updates/releases/latest/download/Soma.dmg), open it and drag
Soma to Applications. It needs macOS 15 or later.
